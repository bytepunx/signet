- Kept the planner's six tasks as drafted (TH-0005); they cover the six criteria and their touches share no path within a layer.
- Layer 1: T-0008 (`scripts/test.sh`), T-0009 (`scripts/integration.sh`), T-0010 (`scripts/smoke.sh`, `tests/smoke/README.md`), T-0011 (`scripts/lint.sh`, `Makefile`). No path in common, so they run together.
- Layer 2: T-0012 waits for T-0011 because both edit the root `Makefile`.
- Layer 3: T-0013 waits for all five because it documents what they built.
- Added T-0019 (remediation) after T-0011 found existing lint failures: five golangci-lint findings in client-go tests and rustfmt drift in client-rust. The root pre-commit hook would block every commit until they pass. T-0019 runs in layer 2 beside T-0012, since they share no path. T-0013 now also waits for T-0019.
- Widened T-0012 to `scripts/golangci-lint.sh` and `scripts/lint.sh`. The PATH golangci-lint is v2 and refuses the v1 `server/.golangci.yml`. One resolver script, a v1 from PATH or the pinned v1.64.8 via `go run`, serves `scripts/lint.sh`, `githooks/pre-commit`, and `server/Makefile`'s `lint`, so the fallback is written once.
- Tagged S-0004 `server` because flai's `story.component-tag` asked for a component: its one change inside a component is `server/Makefile`. The client-go and client-rust fixes are incidental patches.
- Added the top-level `githooks/` and `tests/` folders, which `CLAUDE.md`'s layout table does not list. Criterion 5 names one root `githooks/`, and `code-quality.md` puts smoke tests in `tests/smoke/` at the root.
- T-0013 was written by the story's agent rather than a sub-agent: two short documents whose facts were already in context.
- The `install-hooks` targets were verified in a scratch `git init` repository, not this clone, whose git config is shared with the main checkout and S-0001's worktree. There, `make install-hooks` and `make -C server install-hooks` both set `core.hooksPath=githooks`, and a failing hook blocked the commit. Separately, the real `githooks/pre-commit` blocked an unformatted Go file in the worktree.
- Added T-0020 (remediation) after the second close-out stopped at the test tier. The Buf Schema Registry rate-limited `buf generate` in client-rust (I-0005). `buf.gen.yaml` pins every stub input, so `test.sh` now regenerates only when the stub folder is missing or older than it.
